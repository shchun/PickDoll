# Google Play Games 연동 준비 메모

1주차에서는 연동 조건만 정리한다. 실제 인증·업적 구현은 8주차, Saved Games는 9주차이며 아직 서비스가 연결되어 있지 않다.

## 후속 구현 전 확정

- 최종 패키지명: 현재 개발용 `com.precipi.pickdoll`을 임시 사용. Play Console 앱 생성 전에 확정.
- Play Console 앱과 Play Games Services 게임 리소스 연결.
- 인증에 사용할 디버그·업로드·Play App Signing 인증서 지문 구분. 로컬 APK와 Play 설치본은 서명이 다를 수 있음.
- 테스트 사용자 계정 등록 및 Play 테스트 트랙에서 인증 확인.
- 공식 Google Play Games Unity 플러그인의 적용 버전을 당시 Unity·Android 도구와 함께 검증하고 고정.
- 계정 인증 취소·실패 시 게스트 플레이 유지. 사용자에게 로그인 강요하지 않음.
- Saved Games 활성화, 저장 데이터 버전, 계정 연결·변경 정책 준비.
- 업적 이름·설명·아이콘·ID 등록. 수집 기록의 원본은 업적 서비스가 아닌 게임 저장 데이터.

## 서비스 경계

- 인증: 플레이어 ID 및 서비스 이용 가능 상태를 반환.
- 업적: 누적 획득 수에서 달성 여부를 계산해 반영. 재시도해도 중복 해금으로 수집 수를 늘리지 않음.
- 저장: 로컬 저장을 우선 완료하고 클라우드 전송은 재시도 가능하게 분리.
- 계정별 저장 영역: 로그아웃·다른 계정 전환 시 자동 합산 금지.

## 시험 시나리오

1. 로그인 없이 9개 획득 → 10개 → 앱 재시작 후 10개 유지.
2. 로그인 후 10개 업적 반영 → 재동기화 후 10개 유지.
3. A 기기 클라우드 저장 → B 기기 복원 → 종류별 획득 수·도감 확인.
4. 같은 저장에서 A·B 각각 오프라인 획득 → 순서를 바꿔 동기화 → 중복·손실 없음.
5. 게스트 기록과 기존 계정 기록 연결 → 처리 결과 확인 → 재연결 중복 없음.
6. 클라우드 저장 후 앱 삭제·재설치 → 같은 계정 복원.
7. 다른 계정 선택 → 기존 계정 기록과 섞이지 않음.
